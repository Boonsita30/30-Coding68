program name :โปรแกรมการคำนวณเวลาการอ่านหนังสือหลังเลิกเรียน
โปรแกรมการคำนวณเวลาอ่านหนังสือ คำนวณเพื่อให้เวลาพักผ่อนหรือเวลาส่วนตัวของผู้ใช้เหมาะสมกับเวลาในการอ่านหนังสือมากขึ้น
1.ที่มาและความสำคัญ(Introduction)
>ปัญหาและความสำคัญ : การที่ผู้ใช้ต้องการที่จะอ่านหนังสือหลังจากกลับมาจากที่ทำงานหรือกลับมาจากที่โรงเรียนแต่ไม่สามารถคำนวณเวลาเองได้ โปรแกรมนี้สร้างมาเพื่อตอบโจทย์ผู้ใช้ค่ะ
>คำนวณเวลาได้อย่างชัดเจนและตรงตามที่ผู้จัดทำสร้างขึ้นเพื่อให้ตอบโจทย์ผู้ใช้เป็นอย่างมาก

2.ความสามารถของโปรแกรม (Features)
>Timing: สามารถเลือกกำหนดเวลาตามที่ผู้ใช้ต้องการและคำนวณเวลาออกมาได้เหมาะสม โดยที่ตัวโปรแกรมจะระบุให้อย่างชัดเจนว่าควรอ่าน/ไม่ควรอ่านหนังสือเวลานี้หรือไม่เพราะเหตุใด

3.เครื่องมือที่ใช้ (Tech Stack)
>Language Python
>Ipython.display(จัดการการแสดงผล)
>Platfrom: Google colab
